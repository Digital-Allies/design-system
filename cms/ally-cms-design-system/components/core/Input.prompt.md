# Input

Text input field with optional label and error state. Used for forms across the CMS.

## Usage

```jsx
<Input label="Page Title" placeholder="Enter title..." />
<Input label="Email" type="email" error="Invalid email" />
<Input disabled value="Read-only" />
```

## States

- **Default**: Charcoal border
- **Error**: Red border with error text
- **Disabled**: Reduced opacity
